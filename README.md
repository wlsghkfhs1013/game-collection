# Community Arcade Hub 🎮

An open web arcade where users can play, rate, review, and publish HTML5/JavaScript web games directly in their browser.

## Features

- 🕹️ **Sandboxed Web Games**: Run client-side HTML5/Canvas/JS games safely inside iframe sandboxes.
- ⭐ **Ratings & Reviews**: 5-star rating breakdown, user comments, and helpful votes.
- 🏷️ **Popular Tags Cloud**: Interactive tag cloud with visual popularity weighting and quick filtering.
- 👥 **Creator & Tag Follow**: Follow game creators and favorite tags to create a personalized "Following" game feed.
- 📤 **Game Publisher**: 1-click publishing for web games with code editor and live preview.
- 🌐 **Responsive & PWA Ready**: Fast and mobile-friendly with Tailwind CSS and Vite.

## Quick Start

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Free GitHub Pages Deployment

This repository includes a pre-configured GitHub Actions workflow (`.github/workflows/deploy.yml`).
To activate your free GitHub Pages website:

1. Push this repository to GitHub.
2. Go to **Settings** > **Pages** in your GitHub repository.
3. Under **Build and deployment** > **Source**, select **GitHub Actions**.
4. Your site will automatically build and publish to `https://<your-username>.github.io/<repo-name>/`!
